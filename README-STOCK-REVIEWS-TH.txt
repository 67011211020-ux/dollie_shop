วิธีเปิดใช้สต็อกและรีวิวหลังซื้อ
1. สำรองฐานข้อมูล dollie_shop ใน phpMyAdmin ก่อน
2. เลือกฐานข้อมูล dollie_shop > SQL > รัน sql/add_stock.sql เพียงครั้งเดียว
3. ถ้ามีคอลัมน์ stock อยู่แล้ว ไม่ต้องรันซ้ำ
4. เข้า Admin > จัดการสินค้า > แก้ไข แล้วกำหนดจำนวนคงเหลือของแต่ละสินค้า (สินค้าเดิมเริ่มที่ 0)
5. รัน go run . ใหม่ และทดสอบสั่งซื้อ: จำนวน stock ลดลงเมื่อยืนยันคำสั่งซื้อ
6. ลูกค้าที่มีคำสั่งซื้อสินค้านั้นและไม่ได้ถูกยกเลิกจึงเขียน/แก้ไขรีวิวได้ คะแนน 1–5 ดาว
หมายเหตุ: การยกเลิกคำสั่งซื้อในระบบเดิมยังไม่คืนสต็อกอัตโนมัติ แอดมินต้องปรับจำนวนคืนเอง
