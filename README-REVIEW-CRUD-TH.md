# รีวิว CRUD พร้อมตรวจสอบเจ้าของ

## อัปเดตฐานข้อมูล
- ติดตั้งใหม่: ใช้ `sql/schema.sql` ตามขั้นตอนเดิม
- ฐานข้อมูลเดิม: รัน `sql/reviews_owner_crud_migration.sql` **ครั้งเดียว** ก่อนเปิดแอปเวอร์ชันนี้

## กติกา
- Create: ต้องมีคำสั่งซื้อสินค้านั้นสถานะ confirmed/completed และจำนวนรีวิวทั้งหมด (รวมที่ลบแล้ว) ต้องไม่เกินจำนวนคำสั่งซื้อที่เข้าเงื่อนไข
- Read: แสดงเฉพาะรีวิวที่ไม่ถูกลบ
- Update/Delete: ใช้ user_id จาก session ใน SQL WHERE; ไม่เชื่อ user_id จากฟอร์ม
- Delete เป็น soft delete เพื่อไม่คืนสิทธิ์รีวิวเดิม

## ทดสอบด้วยฐานข้อมูลจริง
1. สมัคร User A, User B และมี Admin; Login/Logout และตรวจ password_hash ว่าไม่ใช่รหัสผ่านดิบ
2. ยืนยันคำสั่งซื้อสินค้าเดียวกันของ A และ B จาก Admin แล้วให้ทั้งสองเขียนรีวิว
3. A แก้ไขและลบรีวิวของ A ได้; A ส่ง POST เพื่อแก้/ลบ id ของ B (พร้อม CSRF ของ A) ต้องได้ 403 และข้อมูล B ไม่เปลี่ยน
4. หลัง A ลบรีวิว A ต้องไม่สามารถรีวิวซ้ำด้วยสิทธิ์คำสั่งซื้อเดิม
5. User A เข้า endpoint Admin ต้องได้ 403; Admin เข้า Dashboard และจัดการสินค้าได้
6. ทดสอบฟอร์มติดต่อร้านและฟอร์มรีวิว บันทึกฐานข้อมูลแล้วแสดงผลอีกครั้ง

หมายเหตุ: ต้องทดสอบ runtime ด้วย MySQL ที่ตั้งค่าจริงก่อนส่งงาน
